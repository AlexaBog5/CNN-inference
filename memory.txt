We quantize the weights to reduce memory usage.
Each weight is stored as int8_t (signed char) instead of float.
Additionally, a scale (float) and a zero point (int8_t) are stored per layer.
Biases remain as float, since their number is relatively small and they have a higher impact on numerical precision.

Storage requirements for weights per layer:
before quantization: sizeof(float) * num_weights = 32num_weights bit
after quantization: sizeof(int8_t) * num_weights + sizeof(int8_t) + sizeof(float) = 8num_weights + 8 + 32 = 8num_weights + 40 bit
difference: 24num_weights - 40 bit

For lenet:
num_weights = 6*1*5*5 + 16*6*5*5 + 16*5*5*120 + 120*84 + 84*10
difference = 24 * 61470 - 40 = 1475240 bit
